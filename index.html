Installation guide ↗Provider setup ↗
Terminal / Bash
# Get the source
git clone https://github.com/faktotum-project/bitcode.git
cd bitcode

# Install without optional wallet builds
npm ci --ignore-scripts

# Check your setup and configure a provider
node bitcode.mjs doctor
node bitcode.mjs login openai
node bitcode.mjs -m openai/gpt-6-astra

Inside the agent

Use /login to configure another provider, /setting to inspect your setup, and /help to explore commands. Ollama uses a running local model and needs no API key.

Cashu and Wavelength need optional binaries. Run doctor to see what is available, and follow the setup instructions for the tools you need.
